## Overview

**MANAGEMENT-HOTEL** là hệ thống quản lý khách sạn toàn diện, được xây dựng dựa trên **Laravel** (backend) kết hợp **Vue 3 + Vite** (frontend). Dự án giúp chuyển đổi ngành dịch vụ lưu trú với trải nghiệm quản lý liền mạch, giao diện hiện đại và các tính năng báo cáo trực quan.

### Tại sao chọn MANAGEMENT-HOTEL?

- Tích hợp command-line mạnh mẽ qua Laravel Artisan
- Frontend nhanh, reactive với Vue 3 + Vite
- Dashboard quản trị với biểu đồ doanh thu, tình trạng phòng (Chart.js)
- Phân quyền vai trò bảo mật (Admin, Nhân viên, Khách hàng)
- Quản lý nội dung phong phú: bài viết, slider, đánh giá
- Seeder tự động để setup nhanh chóng và testing

## Getting Started

### Prerequisites

Dự án yêu cầu các công cụ sau:

- **PHP** ≥ 8.1
- **Composer** (để quản lý package PHP)
- **Node.js** ≥ 18 + **npm** (để quản lý package JavaScript)
- **Laravel** ≥ 10 (khuyến nghị)
- MySQL hoặc PostgreSQL (database)
- Git
